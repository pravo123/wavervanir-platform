Agent-callable systemic risk
The same engines behind this terminal are exposed as Model Context Protocol (MCP) tools, so your AI copilot — Claude Desktop, a custom agent, any MCP client — can query governed systemic risk directly. Every response carries a reproducibility SHA-256 + provenance, so an agent's answer is content-addressed and audit-traceable — the trust gap a regulated institution has when it lets an LLM touch risk numbers. Computed from the public cbsrm methodology only.

cd api
pip install -e '.[mcp]'
